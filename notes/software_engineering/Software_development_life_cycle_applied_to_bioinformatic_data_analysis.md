# Software Development Life Cycle (SDLC)
# applied to bioinformatic data analysis projects

1. Planning
- requirements are gathered
 - Users/stakeholders:
    - PIs, students (pointsperson), collaborators, data providers
 - Purpose: 
    - What is the biological question?
    - What is the context?
    - Has there been previous work? Reference?
  - Input/Output
    - data sets
    - deliverables
      - data files
      - documentation
      - repositories
      - reports
  - Quality assurance
    - data qc
    - FAIR principles
  - Compliance
    - ethics
    - privacy
    - security
- requirements are analysed:
    - Resources (time/cost):
      - Data availability
      - HPC/ cloud computing
      - labour
      - third party tools
      - bottlenecks
- requirements are documented:
    - Project proposal (user requirement specification by user stories/ examples)
    - Software requiremen specifications
    - Data management plan (systems requirement specification)
    - invoice for costs
    - establish time lina
    - (metadata)
- requirements are agreed

2. Design
- develop architecture (prototyping):
    - establish experimental design
    - select analysis workflow (tools, modifications)
- confirm time line
- document analysis/design

3. Development/implementation
- Data management
  - aquire data
  - aquire metadata
  - document data

- Data processing and analysis
  - set configurations
  - coding (pipeline, workflows)
  - data exploration
  - data analysis
  - modelling

4. Testing
- bugs
- interpretation
- check with requirements

5. Deployment
- publish report
- user aceptance -> deliverables
